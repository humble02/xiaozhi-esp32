# 湾湾小何 · 文字转 OGG

Windows 本地工具，输入文字，通过自己已激活的 SparkBot 当前小智角色生成语音，再导出固件可用的 OGG/Opus。便携版双击 `双击启动.cmd`，无需安装 Python 或另配 TTS API。

## 使用

1. 用原生 USB 接口连接这台 ESP-SparkBot。设备应已联网、激活，小智控制台角色保持“湾湾小何”。关闭串口监视器和其他占用串口的软件。
2. 打开工具，刷新并选择串口，输入想让它说的文字。
3. 选择“问候语”“告别语”或“其他提示语”，选择输出目录，点击“生成 OGG”。
4. 工具会临时暂停设备，读取现有连接信息，通过正常语音会话请求朗读，核对返回文字，再自动恢复设备。通常需要几十秒；内容有偏差或丢包时最多尝试三次。
5. 成功后点“试听”，检查读音和完整性，再点“打开输出目录”。输出 `.ogg`、试听用 `.wav`、包含文字及音频校验信息的 `.json`。

电脑需要能访问小智服务端；生成时不使用电脑麦克风。Windows 需有简体中文的 Microsoft Huihui 语音组件，用来生成发送给小智的朗读指令；最终导出的声音来自设备当前云端角色。工具不能自动读取角色名称，若以后改了云端角色，输出声音也会跟随改变。

这条途径使用小智正常对话，而非独立 TTS 接口，因此识别或回答可能改字、加词。工具忽略标点和空白比较文字，保留数字及正负号差异；不一致时不导出并提示重新生成。即使文字核对通过，仍建议试听确认发音。它不是离线音色模型，也不保证小智服务端未来接口始终不变。

## 替换固件

输出文件名带时间，避免覆盖已有文件。确认试听后，将选中的 OGG 复制到源码 `main/assets/common/`：

- 开始提示语重命名为 `touch_greeting.ogg`。
- 结束提示语重命名为 `touch_farewell.ogg`。
- 同步修改 `main/application.cc` 中对应的屏幕显示文字。
- 重新编译 `esp-sparkbot-touch` 并烧录。只复制文件到源码不能直接改变设备中的声音。

转换参数：单声道、16kHz、Opus 20kbps、60ms 帧，末尾追加 250ms 静音。工具会解析并校验 OGG CRC、Opus 类型、声道、采样率、帧时长和播放器容量。超过当前播放器 8 秒上限时拒绝导出，不自动截掉句尾；建议每句控制在约 7 秒以内。

本工具只读取设备配置，不擦除、不烧录、不修改角色。连接凭据只在当前进程内存中使用，不写入导出文件。取消或关闭窗口时会先恢复设备；若运行中拔掉 USB 或强制结束进程导致设备停在下载模式，重新插拔 USB 即可。

便携文件夹的 `app` 是运行依赖，请保留整个文件夹。生成结果在外层 `生成结果` 文件夹，方便单独备份。

## 从源码运行或打包

在 Windows Python 3.12（含 Tk）环境中：

```powershell
python -m pip install -r requirements.txt
python app.py
python -m unittest test_tool -v
python -m pip install pyinstaller
python build_windows.py --output "你的便携工具目录" --work "独立构建目录"
```

可选命令行（同样会临时暂停并恢复指定设备）：

```powershell
python app.py --generate "您好，有什么需要帮忙的吗？" --port COM9 --output "生成结果" --name touch_greeting
```

使用自己设备的端口号。工具当前仅识别 ESP32-S3 原生 USB（VID 303A / PID 1001），仅连接设备已有配置中的小智官方服务端。
