# 文字转 OGG 工具验证记录

日期：2026-10-24，Windows 11、Python 3.12.5，使用当前已激活的 ESP-SparkBot（原生 USB COM9）和用户已确认的“湾湾小何”角色。

## 自动化检查

`python -m unittest test_tool -v`：8 项测试全部通过。

- 读取真实固件提示语，验证 OGG CRC、截断、损坏以及错误格式拒绝。
- OGG/Opus 分包重建、单声道 16kHz 与 60ms 帧校验、超过 8 秒拒绝。
- 文字核对忽略标点和空白，保留改字、数字、小数点、正负号差异。
- 模拟 NVS 配置，验证页面及条目 CRC、凭据有效读取、损坏数据和非官方目标拒绝。
- 模拟读取失败、生成取消和恢复失败，验证恢复路径及错误提示。
- 三次返回文字不符时不生成音频文件。
- 用实际 FFmpeg 转换导出，验证格式可读、试听 WAV 存在、重复生成不覆盖已有文件。

## 实物与窗口

- 从源码完成“输入文字 → 读取当前设备配置 → 角色语音生成 → 文字核对 → OGG/WAV/JSON 导出 → 恢复设备”的完整链路。
- 在 PyInstaller 便携版实际窗口中输入“您好，有什么需要我帮忙的吗？”，点击生成，返回文字与输入一致并成功导出。OGG 校验通过，约 2.76 秒，试听按钮可操作，无运行错误。
- 实测网络丢包时自动拒绝不完整音频并重试，后续接收完整音频才导出。
- 最终版窗口中点击取消，显示先恢复 SparkBot 再完成取消；串口日志确认设备重新运行，端口已释放。
- 便携版包含 Python、Tk、FFmpeg、串口、MQTT、加密和 Windows COM 依赖，GUI 启动与实际设备生成均已验证。Microsoft Huihui 使用 Windows 已有语音组件。

本次不修改或烧录设备固件，也不改变云端角色；测试结果保存于本地工具输出目录。设备配置只在内存中处理，测试与交付文件不包含连接凭据。

当前服务端正常语音对话会经过识别和模型复述，可能加词、改字或受网络影响。三次失败时需用户重试；不能保证任意文字均一次成功，也不能仅凭文字一致就保证发音完全正确，应试听后再替换固件资源。换另一台设备或电脑、断网恢复、服务端未来变更尚未做全面验证。
